8. Mobile, tablet, and desktop requirements

Mobile requirements:
Use a clean single column layout.
Hero copy must be easy to read without overwhelming the first screen.
Primary CTA should appear above the fold when possible.
CTA buttons must be full width or comfortably tappable.
Minimum tap target should be 44 pixels high.
Navigation must collapse cleanly.
Events must appear inside the mobile menu.
FAQ should use accordion behavior if the current site already uses accordions. If not, use stacked readable FAQ blocks.
Avoid text over images unless contrast is excellent.
Keep line length short and readable.

Tablet requirements:
Use one or two column layouts where appropriate.
Keep section spacing generous but not excessive.
Make sure image and text pairings stack naturally.
Do not allow CTAs to wrap awkwardly.

Desktop requirements:
Preserve premium restaurant feel.
Use strong visual hierarchy.
Use alternating content sections if the current design supports it.
Keep paragraphs constrained to readable width.
Use high quality imagery where available.
Do not make the homepage feel like a long SEO article.

Suggested responsive breakpoints:
Mobile: 0 to 767 pixels
Tablet: 768 to 1023 pixels
Desktop: 1024 pixels and above
Large desktop: 1280 pixels and above
